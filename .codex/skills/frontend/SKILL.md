Paths below are repository-root relative.

1. Read the relevant installed Next.js guide under `node_modules/next/dist/docs/` before code changes, especially `01-app/02-guides/static-exports.md` and `01-app/02-guides/server-and-client-boundary.md`. Inspect `next.config.ts` and the affected section before choosing a rendering boundary.
2. Find composition in `src/app/[locale]/page.tsx`, section implementations in `src/components/home/`, and navigation in `src/components/Navigation.tsx`. Reuse `src/app/globals.css` tokens, classes, dark-theme overrides and breakpoints; `src/components/home/ValueStrip.module.css` is an existing scoped-style example. Illustrations use CSS/SVG and local fonts rather than external font/image services. Consult `README.md` for content constraints, including the scoped prototype estimate and prohibition on fabricated proof points.
3. Update `messages/en.json` and `messages/cs.json` together. Compare nested key sets, value shapes and ICU interpolation parameters; render both locales to catch translation and layout errors. Sections own their translated copy. Inspect `src/app/[locale]/layout.tsx` for metadata, alternates, static locale parameters and the existing Czech `noindex` behavior; do not silently change indexing policy.
4. Preserve locale handling in `src/i18n/`: `routing.ts` defines `en`/`cs` with locale cookies/detection disabled, `request.ts` uses `next/root-params`, and `server.ts` handles promised params. Use `navigation.ts` for localized navigation. `src/components/LocaleEntry.tsx` performs the root browser redirect and captures UTM first; `preference.ts` stores the explicit choice in localStorage. Explicit locale URLs take precedence. Theme startup spans `src/components/SiteDocument.tsx`, `ThemeProvider.tsx`, `ThemeToggle.tsx` and `public/theme-preference.js`; preserve first-paint and blocked-storage behavior.
5. Keep browser APIs inside browser execution paths even in client components, which are prerendered. Production is `output: "export"` with unoptimized images; dev deliberately omits export mode. Do not add request-time cookies, server actions or a Next.js contact POST endpoint to this architecture. Reuse `src/components/motion/Reveal.tsx` and `WorkflowMotion.tsx`: initial content stays visible (`initial={false}`), entrance and hover transforms are separate, and reduced-motion removes delays/movement. Preserve semantic controls, keyboard focus and responsive overflow behavior.
6. Run root `npm run lint`, `npm run typecheck`, `npm run build`, then the relevant browser suites using [the verification skill](../verify/SKILL.md). Completion means both locales render with matching message structure, light/dark and mobile layouts work, and changed interactions retain keyboard and reduced-motion support. Report any checks unavailable locally.
